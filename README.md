# Data Autopilot

Interview demo: an agent-shaped ELT control plane that lands SQL data in S3 as Parquet and registers it in Glue. Orchestrated by GitHub Actions. Authenticated to AWS with OIDC. **No Airflow. No Airbyte. No long-lived AWS keys.**

This is not “I replaced data engineers.” It is “I automated the repeatable JDBC/SQL → lake boilerplate.”

## What you get

| Piece | Role |
| --- | --- |
| `agent/index.html` | Cheap UI: form + chat-style questions |
| `agent/generate.py` | Writes `pipelines/conf/pipeline.yaml` |
| `pipelines/ingest.py` | dlt extract → S3 Parquet |
| `pipelines/register_glue.py` | Glue tables, no crawler |
| `infra/` | S3, Glue DB, GitHub OIDC role, $5 budget |
| `templates/github-workflows/` | Action YAML to copy into `.github/workflows/` |

Default source is a tiny **Chinook** SQLite database generated by `samples/build_chinook.py`. Swap to a real database later with GitHub secret `SOURCE_DATABASE_URL` and `source.type: sqlalchemy`.

## Enable GitHub Actions (required once)

The GitHub MCP token can write repo files, but **not** `.github/workflows/` (needs the extra `workflow` scope). Copy these two files in the GitHub UI:

1. Open [templates/github-workflows/ingest.yml](templates/github-workflows/ingest.yml) → copy
2. Repo → **Add file** → **Create new file** → path `.github/workflows/ingest.yml` → paste → commit
3. Repeat for `generate.yml` → `.github/workflows/generate.yml`

Then: Terraform (below) → set secret/variable → Actions → **ingest** → Run workflow.

## One-time AWS setup

1. Apply Terraform — see [docs/aws-bootstrap.md](docs/aws-bootstrap.md)
2. Set GitHub secret `AWS_ROLE_ARN` and variable `LAKE_BUCKET`
3. Actions → **ingest** → Run workflow
4. Query Glue/Athena

## Agent loop

1. Answer questions in `agent/index.html` or run workflow **generate-pipeline**
2. That updates the contract only (no secrets)
3. **ingest** loads data

## Limits

- GitHub-hosted runners cannot see a database on your laptop or in a private VPC.
- “Any JDBC driver” needs a JVM (Glue/Airbyte). This demo uses SQLAlchemy.
- Notion cannot log into AWS. Notion is docs + the custom agent that edits this repo.
